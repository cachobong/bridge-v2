# supabase
Database schema (migrations) and local Supabase config.

## Inputs
- `_config/architecture.md` (Data access and security), `_config/domain.md`, `_config/rbac.md`
- `supabase/migrations/*.sql` (read the latest before you add one)

## Process
- Add a new migration for each change. Do not edit a migration that ran on a shared database.
- Every new table: `enable row level security` with no policies (only the API service role reads it).
- Keep DB checks in sync with `packages/shared` rules (payroll dates, worker type fields, permissions).
- After a change: `pnpm db:reset` → `pnpm db:types` → `pnpm db:seed`.
- `config.toml`: public sign-up is off; `site_url` is the web dev URL.

## Outputs
- `supabase/migrations/<timestamp>_<name>.sql`
- `apps/api/src/lib/database.types.ts` (generated by `pnpm db:types`)
